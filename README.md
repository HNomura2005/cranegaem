# PAKIRA Robot Controller
### ESP32とブラウザーをつなぐクレーンロボット用コントローラー

USB接続したESP32をWebブラウザーから操作する、ロボット制御プロジェクトです。専用のデスクトップアプリを用意せず、ブラウザー上のボタン・キーボード・ゲームパッドから操作できる構成にしています。

**ESP32 · C++ / Arduino · JavaScript · Web Serial API**

[操作画面のソース](outputs/scara_web_serial_control/index.html) · [ファームウェア](outputs/scara_web_serial_control/ArduinoMegaScaraControl.ino) · [セットアップ・配線・通信仕様](docs/SETUP.md)

## プロジェクト概要

| 項目 | 内容 |
| --- | --- |
| 制御対象 | J1・J2・Z軸のステッピングモーター、把持用サーボ |
| 操作方法 | 画面ボタン、キーボード、ゲームパッド |
| 通信 | USBシリアル、115200bps、改行区切りのテキストコマンド |
| 状態表示 | 通信ログ、ステップ数に基づく簡易レーダー |
| 開発状況 | 実機向けの試作・開発段階 |

## 実装のポイント

- **ブラウザーと組み込み制御の接続**：Web Serial APIでコマンドを送信し、ESP32で解析して各アクチュエーターに反映します。
- **操作と状態表示の往復通信**：500ms間隔で位置情報を取得し、画面の簡易レーダーを更新します。
- **複数の入力方法**：マウス操作に加えて、キーボードとGamepad APIによる入力に対応しています。
- **モーターとサーボの統合**：AccelStepperとESP32Servoを用い、速度指定と把持角度の操作を一つの画面にまとめています。

## まず画面を確認する

リポジトリを取得し、ルートで次を実行します。

```bash
python -m http.server 8000
```

デスクトップ版ChromeまたはEdgeで <http://localhost:8000> を開きます。実機がなくても画面を確認できます。ロボットを動かす場合は、[セットアップガイド](docs/SETUP.md)のボード設定・ライブラリ・GPIOを確認してください。

## 現在の制約と改善候補

J1・J2の連続駆動は排他制御です。位置表示はステップ数からの概略表示で、センサーによる実測ではありません。`HOME`は設定されたゼロ位置への移動で、原点センサーの探索ではありません。

今後の改善候補は、通信断時の停止処理、リミットスイッチへの対応、機構に合わせた位置表示の校正です。画面の「全停止」はソフトウェア上の駆動停止であり、電源遮断ではありません。

実機の動作写真・動画や再現試験の結果は、まだこのリポジトリに掲載していません。
