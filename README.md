# PAKIRAロボ コントローラー

ブラウザーからUSBシリアル通信でESP32を操作する、クレーンロボット用コントローラーです。J1・J2・Z軸のステッピングモーターと、把持用サーボを制御します。

## 構成

| 層 | 使用技術 | 役割 |
| --- | --- | --- |
| 操作画面 | HTML / CSS / JavaScript | 手動操作、通信ログ、位置の簡易表示 |
| 通信 | Web Serial API / USB | 改行区切りのコマンドと状態の送受信 |
| ファームウェア | ESP32 / Arduino / C++ | コマンド解析、モーター・サーボ制御 |
| ライブラリ | AccelStepper / ESP32Servo | ステップ信号生成とPWM出力 |

## 実装している機能

- ボタン・キーボード・ゲームパッドによる操作
- アーム2軸とZ軸の速度指定、把持用サーボの角度指定
- 現在位置のゼロ設定とソフトウェア上の全停止
- 500ms間隔の状態取得、受信ステップ数に基づく簡易レーダー表示

J1とJ2の連続駆動にはファームウェア側で排他制御があり、同時駆動は行いません。レーダーはステップ数から算出した概略表示で、実測位置ではありません。

```text

outputs/scara_web_serial_control/
```

ファームウェアのファイル名にはArduino Megaの表記が残っていますが、現在のコードはESP32用です。

## 起動方法

1. Arduino IDEにESP32用ボード環境、AccelStepper、ESP32Servoを導入します。
2. `ArduinoMegaScaraControl.ino`を同名フォルダーに置き、使用するESP32ボードとポートを選んで書き込みます。
3. このリポジトリのルートで次のコマンドを実行します。

   ```bash
   python -m http.server 8000
   ```

4. デスクトップ版ChromeまたはEdgeで <http://localhost:8000> を開きます。
5. ESP32をUSB接続し、「ESP32に接続」から対象のシリアルポートを選択します。通信速度は115200bpsです。

画面だけの確認は実機なしでも可能です。実機制御にはWeb Serial APIに対応したブラウザーと、localhostまたはHTTPSの環境が必要です。

## ピン設定

現在のソースに記載されたGPIO番号です。実際の配線と一致することを確認してください。

| 用途 | STEP | DIR |
| --- | --- | --- |
| J1 | 25 | 22 |
| J2 | 27 | 14 |
| Z | 33 | 32 |

- ドライバー共通ENABLE：GPIO16（LOWで有効）
- 把持サーボ：GPIO13
- AccelStepper内部用のダミーDIR：GPIO4・5・18（実ドライバーのDIRには使用しません）

## 通信コマンド

各コマンドの末尾に改行を付けて送信します。

| コマンド例 | 動作 |
| --- | --- |
| `DRIVE J1 100` | J1を指定速度で連続駆動（steps/s） |
| `DRIVE J1 0` | J1の連続駆動を停止 |
| `JOG J2 100` | J2を相対ステップ数で移動 |
| `Z 100` | Z軸を指定ステップ位置へ移動 |
| `ARM 70` | オフセットを加えた論理角度でサーボを操作 |
| `SERVO_ADD -5` | 現在のサーボ角度を相対調整 |
| `SERVO_ZERO` | 現在のサーボ角度を論理角度のゼロに設定 |
| `ZERO` | 全軸の現在位置をゼロに設定 |
| `HOME` | 設定されたゼロ位置へ移動 |
| `STOP` | ステッピングモーターの駆動を停止 |
| `STATUS` | ステップ位置とサーボ角度を取得 |

`HOME`はセンサーによる原点探索ではありません。起動時のサーボ指定は170度、画面の把持・解放指定は0度・70度です。機構に合わせた調整が必要です。
